Plumbing tables that don't change (role_permissions, user_sessions, user_preferences, saved_views, settings, student_field_definitions) are left out of the picture to keep it readable.

New tables at a glance

  • TEACHER_STUDENTS — which teacher is responsible for which student (so a teacher sees "their" students only).
  • PARAMETER_ASSIGNMENTS — which parameters apply to which group or student (parameters stop being global).
  • TASKS + TASK_ASSIGNMENTS — a brand-new "task" idea, handed out to groups/students, optionally tied to a parameter.
  • USER_FIELD_DEFINITIONS — custom fields on user accounts (mirrors the custom fields you already have on students).

New columns on tables you already have

  • students.user_id — links an evaluated student to their own login account.
  • students.period_interval + students.period_anchor — each student's own class rhythm (weekly, every 3 days, monthly…).
  • users.extra — storage for the custom user fields.
  • audit_log.deleted_at + audit_log.delete_reason — lets a log entry be removed only with a written reason.
